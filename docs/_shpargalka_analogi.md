# Шпаргалка: АНАЛОГИ (держать перед глазами)

## Ответ вслух (если спросят «есть ли аналоги»)
Да, идея востребована — вендоры пошли туда же в 2023–2025. Ближайшие — генеративные
ассистенты обслуживания: **IBM Maximo AI Assist**, **Siemens Industrial Copilot**,
**Aquant Service Co-Pilot**. Все — LLM поверх руководств и данных об оборудовании, ответ
на естественном языке со ссылкой на источник.
**Моё отличие (3 вещи):** российская нормативка (ПТЭЭП, РД, ГОСТ) • расчёт просрочки
детерминированно в КОДЕ, не моделью • открытый прототип под GigaChat/YandexGPT для
закрытого контура. Западные — закрытые, часть ушла с РФ-рынка.

**Фраза-вывод:** моя ниша на пересечении — RAG по нормативке + данные парка +
детерминированный расчёт. Ни одна из 4 групп её не закрывает.

## Про живое демо аналогов
Западные вживую показать НЕЛЬЗЯ — закрытые, под корпоративные внедрения. Из открытого —
PrivateGPT/RAGFlow на GitHub, но они без учёта оборудования.
**Мой живой «аналог» = переключатель «Агент / Чистый RAG» в моём приложении:**
чистый RAG = упрощённая версия конкурентов (только документы), агент = моё решение
(документы + база парка + расчёт).

## РФ-рынок: LLM+RAG-чат — есть или нет? (важный вопрос)
Отвечать на ДВУХ уровнях — это и есть сильная позиция.

**Уровень 1 — технология LLM+RAG-чат по документам: НА РФ-РЫНКЕ ЕСТЬ.**
- YandexGPT Pro / Yandex AI Studio — прямо заявлен RAG-сценарий (поиск по базе знаний + генерация).
- GigaChat (Сбер), MTS AI Cotype — модели + API под чат-ассистентов по своим данным.
- Студии-интеграторы (aritin, doubletapp, allsee.team) — «ИИ-ассистент с базой знаний RAG» уже типовая услуга.
- Вывод: сам паттерн «RAG-чат по своим документам» — коммодити, не новость.

**Уровень 2 — МОЯ комбинация как коробочный продукт: НЕТ.**
Готового решения, где в одном: (1) RAG по российской нормативке ТО (ПТЭЭП, РД, ГОСТ) +
(2) структурированная база парка + (3) детерминированный расчёт просрочки в коде — НЕТ.
Есть либо generic-конструкторы (Яндекс/Сбер, без предметной модели ТОиР), либо ТОиР-системы
(1С:ТОиР, без диалога по нормативке), либо ИИ-диагностика в ТОиР как заказные пилоты
(Северсталь, Газпром нефть, Росатом). Коробки с моей сборкой нет — эту нишу я и занимаю.

### Текст вслух — «а на РФ-рынке есть?»
«Если про технологию — LLM+RAG-чат по документам на РФ-рынке уже есть: YandexGPT Pro с
RAG-сценарием, GigaChat, MTS Cotype, плюс студии делают на заказ. Но это generic-конструкторы:
грузишь свои документы, предметной модели нет. Готового продукта именно с моей комбинацией —
RAG по российской нормативке ТО плюс база парка плюс детерминированный расчёт просрочки в
коде — на рынке нет. Только внутренние пилоты у Северстали, Газпром нефти, Росатома. Эту нишу
я и занимаю.»

### Если дожмут — «значит, новизна не в технологии?»
«Верно — новизна не в самом RAG, он коммодити. Новизна в сборке: соединение семантического
поиска по нормативке со структурированными данными парка и детерминированным расчётом
регламентной просрочки в одном диалоговом решении. Этого не закрывают ни RAG-конструкторы,
ни ТОиР-системы.»
